Description

Let's modify our system such that when a user requests information, it is retrieved from a vector database. The vector database should store embeddings of planet information. When a query is issued, the relevant document should be retrieved. Finally, print the contents of the retrieved document. To keep things simple, you are required to use the Chroma vector store.

Objectives

Your implementation should:

  • Load planetary descriptions from the text files in the planets/ directory.

  • Convert this data into vector embeddings using any embedding model.

  • Store embeddings in the Chroma vector store.

  • Fetch relevant documents based on user queries.

  • Print the contents of the most similar document.

Examples

The greater-than symbol followed by a space (> ) represents the user input. Note that it's not part of the input.

Example 1: Which planet supports life?

> Which planet supports life? 
Earth
Earth is the third planet from the Sun and the only known planet to support life.
It has a diverse environment, liquid water on its surface, and a protective atmosphere that sustains life.

Example 2: Which planet is closest to the sun?

> Which planet is closest to the sun? 
Mercury
Mercury is the smallest planet in the solar system and the closest to the Sun.
It has a heavily cratered surface and a very thin atmosphere, leading to extreme temperature variations.
