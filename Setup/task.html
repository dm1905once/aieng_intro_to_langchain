Description

In this stage, you will set up your environment by ensuring you have Python installed and a virtual environment configured. As part of the project, a virtual environment is already configured. Your next task is to install key packages such as langchain-groq, langchain_core, and python-dotenv. You can start experimenting with Groq chat models for free by signing up for an API key. If you plan to use another provider such as OpenAI, install langchain_openai instead.

Next, configure your project’s .env file by adding your API keys GROQ_API_KEY (or OPENAI_API_KEY if using OpenAI).

Hyperskill does not track or store the .env file. However, if you plan to share your project to GitHub or other VCSs, ensure to exclude it (via .gitignore) to avoid sharing it with the public.

Once your environment is ready, use the following code to test if everything is set up correctly:

# install the required packages:
# pip install langchain-core python-dotenv langchain-openai
 
from langchain_core.prompts import PromptTemplate
from langchain_openai import ChatOpenAI
import dotenv
import os

dotenv.load_dotenv()

llm = ChatOpenAI(api_key=os.getenv("OPENAI_API_KEY")) # if using a different base_url and model, pass them as well

question = input()
template = PromptTemplate.from_template("You are a helpful assistant who answers questions users may have. You are asked: {question}.")

prompt = template.invoke({"question": question})
response = llm.invoke(prompt)
print(response.content)
# install the required packages:
# pip install langchain-groq langchain-core python-dotenv

from langchain_core.prompts import PromptTemplate
from langchain_groq import ChatGroq
import dotenv

dotenv.load_dotenv()

llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.5, max_retries=2)

question = input()
template = PromptTemplate.from_template("You are a helpful assistant who answers questions users may have. You are asked: {question}.")

prompt = template.invoke({"question": question})
response = llm.invoke(prompt)
print(response.content)

Objectives

Here are the objectives for this stage:

  • Set up your development environment;

  • Install the necessary packages: langchain-groq or langchain-openai, langchain_core, and python-dotenv;

  • Create and configure a .env file with your GROQ_API_KEY or OPENAI_API_KEY to securely manage your API credentials;

  • Paste the provided snippet for your chat model in the main.py file to verify your setup and run tests.
