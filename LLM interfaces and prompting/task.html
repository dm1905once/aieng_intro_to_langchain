Theory

LangChain offers prompt templates that streamline the process of crafting prompts for AI models. This helps ensure that the generated responses meet our requirements. Let's see how LangChain makes it easier to structure prompts using templates.

Prompt templates transform user input and parameters into structured instructions for an LLM. They help shape the model’s response by providing context, ensuring clarity, and guiding it to generate relevant and coherent output. LangChain provides various prompts templates to cater for different use cases: ChatPromptTemplate, FewShotPromptTemplate, ImagePromptTemplate, and so on. In the example below, we use the PromptTemplate class:

# install the required packages:
# pip install langchain-groq langchain-core python-dotenv

from langchain_core.prompts import PromptTemplate
from langchain_groq import ChatGroq
import dotenv

dotenv.load_dotenv()

llm = ChatGroq(model="llama-3.3-70b-versatile", temperature=0.0, max_retries=2)

template = PromptTemplate.from_template("Explain {concept} in simple terms. Your output should be concise and informative.")

prompt = template.invoke({"concept": "black holes"})
response = llm.invoke(prompt)
print(response.content)

As shown here, we can pass the concept as a variable instead of hard-coding it. This flexibility allows us to incorporate user queries dynamically when constructing prompts, making them more adaptable to different inputs. Expand the section below to explore an example using the FewShotPromptTemplate class. This approach enhances the model's response quality by including example question-answer pairs, helping the LLM generate more accurate, well-formatted, and contextually relevant outputs.

Code section
# install the required packages:
# pip install langchain-groq langchain-core python-dotenv

from langchain_core.prompts import PromptTemplate
from langchain_core.prompts import FewShotPromptTemplate
from langchain_groq import ChatGroq
import dotenv

dotenv.load_dotenv()

llm = ChatGroq(
    model="mixtral-8x7b-32768",
    temperature=0.0,
    max_retries=2
)

examples = [
    {"input": "What is AI?", "output": "AI is the simulation of human intelligence by machines."},
    {"input": "What is Machine Learning?", "output": "Machine Learning is a subset of AI that allows computers to learn from data."},
]

example_template = PromptTemplate.from_template("Q: {input}\nA: {output}")

few_shot_prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_template,
    suffix="Q: {question}\nA:",
    input_variables=["question"],
)

final_prompt = few_shot_prompt.format(question="What is Deep Learning?")

response = llm.invoke(final_prompt)

print(response.content)
Description

Now, imagine you are building a question-answering application that provides responses about planets. Instead of requiring users to type full questions, your solution should allow them to input only the planet's name, and the system will automatically format the query using a prompt template. This ensures consistency in how the LLM interprets the request.

Additionally, to enhance response quality, your implementation should leverage the few-shot prompting approach by including example question-answer pairs. These examples will help the LLM generate well-structured, contextually rich, and precise answers by following a predefined pattern.

The final output should provide key details such as the planet’s size, atmosphere, notable features, and any interesting facts.

Objectives

Here are the objectives for this stage:

  • The prompt template should take a planet’s name as input and transform it into a well-structured question for the LLM;

  • Provide examples to guide the AI’s response style, using the appropriate template;

  • Ensure responses are informative by prompting the AI to include essential planetary details such as:

    • Physical characteristics (size, composition, atmosphere);

    • Notable features (rings, moons, surface conditions);

    • Scientific or historical significance;

    • Fun or surprising facts;

  • Format the output for readability to make it easy for users to extract useful information at a glance;

  • This template should work for any planet, allowing users to inquire about multiple celestial bodies effortlessly.
